# ./test — the pytest suite of the evoxc rewrite

## Intent
Prove three separate things about the rewrite: the evoxc kernels are *correct* (unit, against numpy oracles), they are *equivalent* to the frozen legacy library where the legacy semantics are well defined (parity, against `benchmarks/legacy_jax`), and the installed package is *JAX-free, importable end to end and runnable* (the two release gates + integration).
This is a verifier, not a specification: every test body executes a real kernel and asserts on its output.
Every suite reads `../src/tensorneat` and `../benchmarks/legacy_jax` as read-only inputs; nothing in `src/` imports anything from here.
`./support` holds the host-side helpers the suites share (one graph runner, hand-built gene payloads, numpy reference oracles); it is test code and is not packaged.

## How to run
Commands an owner runs from the repo root (`[tool.pytest.ini_options]` in `pyproject.toml` sets `testpaths = ["test"]`, `addopts = "-q"`; a doubled `-q` suppresses the summary line, so read the counts with `-o addopts=""`):
- `pytest -m "not parity and not slow"` — the default gate: all of `./unit` (1313 cases), `./support` (9), the import-hygiene gate's three non-slow cases, the surface gate's five cases and `./backends`' 46 cases (41 guard cases needing no extra, 3 compiled `llvm-cpu` cases and 2 used only when a HIP device is present, which all skip at module level without `evoxc[iree]`); no other optional extra is needed. With every extra installed it selects **1376 cases: 1376 passed, 0 skipped, 121 deselected in ~54 s**. In a bare `uv sync` (`jax` and `iree` absent) it still runs without `--ignore`: **1371 passed, 6 skipped, 85 deselected in 37.1 s**, the six skips being the four `jax` parity modules and the two `./backends` modules (the guard does not mistake this selector for a capability request, see Known items). The deselected are the 60 `./parity` cases, the 60 `./integration` ones and the import-hygiene gate's end-to-end XOR run.
- `pytest -m parity` — kernel equality against the frozen legacy JAX implementation; needs the `bench` extra and collects/passes **60 cases**. Without a usable `jax` the four oracle modules skip at import but the run is **22 passed, 6 skipped, 0 failed** (18 library-free `test_convert` cases + the 4 always-run oracle-independence cases in `test_oracle_integrity.py`; the four oracle modules and that module's two jax-dependent guards each skip with a reason naming the missing modules), and its collection ratchet fails the run if the directory is collected with fewer items than its documented constant while jax is importable — a bare environment is *explicit*, never a silent 18-test green.
- `pytest -m slow` — `./integration` (60 cases: XOR evolution, determinism, rebuild-on-shape-change, checkpoint round-trip, chunk-budget neutrality, the `host_payload=False` contract, the executable-cache signature, CartPole goldens, the ask hook, auto-run stopping, detail failures and the HyperNEAT pipeline runs) plus the import-hygiene gate's end-to-end XOR run: **61 passed, 0 skipped, 1436 deselected** with every extra installed, and the same 61 with the six optional-dependency skips when `jax` and `iree` are absent.
- `pytest test/release_gate_no_jax.py test/test_release_gate_surface.py` — both release gates together, no optional dependency and no fixture; **9 passed** (4 import-hygiene cases, 5 surface cases).
- `pytest test/release_gate_no_jax.py` — the import-hygiene gate alone; **4 passed** (1 marked `slow`).
- `pytest test/test_release_gate_surface.py` — the surface gate alone; **5 passed**.
- `pytest` (no marker) — the whole tree: **1497 passed, 0 skipped, 0 failed in 105.8 s with every extra installed** (no `xfail` left), and **1454 passed, 8 skipped, 0 failed in 65.4 s** in a bare `uv sync` (the eight skips are the four `jax` parity modules, `./parity/test_oracle_integrity.py`'s two jax guards and the two `./backends` modules).
- `pytest -m requires_iree` selects **5 cases (3 llvm-cpu + 2 ROCm), 1492 deselected**; `pytest -m requires_rocm` selects **2, 1495 deselected** on a box with `/dev/kfd` and a HIP device.
Markers `parity` and `slow` are declared in `pyproject.toml`; `requires_iree` and `requires_rocm` are declared in `conftest.py` and are in no gate (they need `evoxc[iree]`, and `requires_rocm` additionally an AMD GPU).

Every directory that holds test modules carries an `__init__.py`: pytest's default prepend import mode names a module by its basename, so un-namespaced directories collide (`test/unit/genome/test_forward.py` vs `test/parity/test_forward.py`) and abort the session with an import-mismatch error.

## What each suite proves
- `./unit/common` — the schedule derived from a hand-built genome has the right level order, incoming-edge windows and sentinels, `validate_schedule` accepts what `derive_schedule` produces and rejects every tampered invariant, flat gather/scatter/mutation helpers agree with a plain-numpy oracle, the ACT/AGG dispatchers agree with a per-option Python loop for all 12 ACT / 6 AGG ids (including `-1` and out-of-range ⇒ identity), `State` is an immutable pytree container, and the host graph walks (`decode_graph`, `topological_sort`, `find_useful_nodes`, `node_depth`, `check_cycles`) agree with the in-graph `node_level`.
`test_schedule_accelerator.py` builds the pop-100 `derive_schedule` graph in `kernel_mode="accelerator"` and proves all 12 `Transformed` leaves bit-identical to the host leg on a cyclic ring, a shallow chain and a `max_nodes` below the 4-step unroll group, with the traced IR showing the accelerator route's flat scatters gone and zero `if` on the feedforward build (the cyclic fallback's one data-dependent `cond` is pinned as documented on both legs).
- `./unit/genome` — forward values on hand-built genomes (dense chain, skipped node, unconnected node ⇒ NaN propagation, activation `-1` ⇒ identity), the recurrent tick, `grad` against the numpy / finite-difference reference, `execute_distance` and the digest/`key_span` distance contract, the genetic operators through their *invariants* (capacity, key uniqueness, in-degree bound, cycle and duplicate rejection, structural stability of crossover), the level-order sweep on an isomorphic relabel whose hidden edges run from a higher node row to a lower one (`test_level_order.py`), plus the host-only helpers (`network_dict`, `sympy_func`, `visualize`, `repr`), the in-graph `hash`, and the prepared-pass split (`forward` == `prepare_pass` + `forward_prepared` bit for bit at `samples` 1/4, the individual-major `(P * S, I)` tiling, the `pop_size * samples` and ragged-batch rejections).
`test_accelerator_equivalence.py` proves `closes_cycle` and the crossover homologue pairing bit-identical host-vs-accelerator on accept/refuse matrices, and `test_forward_accelerator.py` proves the unrolled accelerator level sweep equals the host `while` loop at `samples == 1` (including a network deeper than `max_depth` and a NaN subtree) and that `samples > 1` falls back to it.
- `./unit/algorithm` — speciation, stagnation, spawn allocation, parent selection and `NEAT.tell` bookkeeping: `sum(spawn) == pop_size`, the last-qualifying-block layout rule, damping law and `min_species_size` floor, elite pinning, father-wins-tie, no NaN fitness surviving `tell`, a one-member species never yielding NaN probabilities, every genome ending in exactly one species; the gated/dense `GATED_ROWS` seam proved bit-identical with a spy on the branch actually reached (`test_distance_dense.py`); `test_exports.py` pins the `tensorneat.algorithm` public surface (`BaseAlgorithm`/`NEAT`/`HyperNEAT`/`HyperNEATFeedForward`, exactly those four in `__all__`); and the HyperNEAT subtree has its own behavioural suites — `test_substrate.py` (geometry and the validation matrix on host NumPy), `test_genes.py` (the two substrate gene kernels), `test_hyperneat_weights.py` (the CPPN→weight map), `test_hyperneat.py` (decode algebra, `transform` batch independence, the `forward`/`prepare_forward`/`forward_prepared` split), `test_hyperneat_feedforward.py` (the variant delta and recurrent-substrate rejection) and `test_hyperneat_e2e.py` (pop-4 two-generation `Pipeline` runs of both variants over `CustomFuncFit`).
`test_distance_accelerator.py` proves `DistanceRows.matrix` and three whole-`NEAT.tell` routes identical across all eight `kernel_mode × distance_centre × distance_formulation` combinations (the accelerator grouped and index-free paths included, with trace-time spies proving the routes are really selected), and `test_scan_accelerator.py` pins the `gated()` table (never gated in accelerator mode) and the traced speciate graph's `if` count 4/0/0 for host-gated/host-dense/accelerator with bit-identical results.
- `./unit/problem` — func-fit losses against the closed form for each `error_method`, individual-major dataset tiling order, `NaN` prediction ⇒ `-inf` fitness, `CustomFuncFit` datasets, the `problem` protocol in `test_problem_api.py`, and the three RL environments: `CartPole` against the shared `support.oracle.cartpole_rollout`, and `Pendulum`/`MountainCar` against an in-file host-numpy oracle each (a float32 op-for-op transcription plus a float64 Gym-semantics one; the two dynamics differ, so the oracles are not duplication). Those suites pin pre-transition cost ordering, clip-before-integrate, the floor-mod angle wrap, the one-time goal bonus under the pre-step alive mask, the idle optimum of exactly `0.0`, individual-major `(P, R)` averaging, and NaN poison by arithmetic through the action penalty.
- `./unit/benchmarks` — the benchmark harness fingerprint: `git_report()` on a real temporary git repository created under `tmp_path` (clean tree ⇒ clean, unstaged modification ⇒ dirty, untracked file ⇒ dirty, staged rename ⇒ dirty naming the new path), the porcelain `XY PATH` parser on the documented records, and the `-z` NUL-record reader that consumes a rename's source field; this is the regression suite for the `git_dirty` false-negative (a stripped status line read the path one character short).
- `./unit/test_host_payload.py` — `host_payload._one_individual`'s contract, the funnel `Pipeline.show` and the checkpoint path go through: a one-individual batch (`(1, max_nodes)`, i.e. `state.pop`/`best_genome` at `P = 1`) comes back array-for-array, the bare per-individual rows a checkpoint stores are promoted with a leading axis of 1, a `P > 1` payload and a missing (`None`) payload each raise a `TensorNEATError` naming both accepted spellings, and every malformed-input path keeps its own message.
- `./unit/test_version.py` — `tensorneat.__version__` against the installed distribution metadata, plus the `PackageNotFoundError` fallback to `"0.0.0"` proved by patching the metadata lookup and reloading the module.
- `./parity` — on *identical* genomes: `forward` values and NaN pattern (rtol 1e-5) on chain / skip / isolated / random-DAG genomes, the compatibility distance, `execute_distance` closed forms, `XOR`/`XOR3d` fitness for every `error_method`, and gradients w.r.t. `conn_attrs`/`node_attrs` (rtol 1e-4), plus the lossless-schedule guard in `convert.py` and `test_oracle_integrity.py`'s ratchet and oracle-independence guards (the directory cannot shrink into a silent green when `jax` disappears).

`test_host_payload_flag.py` pins `Pipeline(host_payload=False)` (the opt-out payload is array-for-array the default run's, `materialize_payload` reproduces it and rejects `None` with the flag named, the opt-out leaves are the backend's own objects by identity, and the per-call override follows the caller), and `test_executable_cache.py` pins `eval_chunk_rows`' hand-computed table, its position as the last `_shape_signature` element, and a mid-run budget change forcing exactly one rebuild with a numerically neutral result.
- `./backends` — the compiled legs run a real XOR generation end to end (`setup` + 2 `step`s, finite `(P,)` fitness, one cached build) and agree with numpy on the same seed (int/key payloads exactly, floats within a documented reduction-reassociation tolerance): `test_iree_pipeline.py` on llvm-cpu and `test_rocm_pipeline.py` on a HIP device (`device="rocm"`, `compile_options={"target_backends": ["rocm"]}`), both sharing `_tiny_xor.py`; the llvm-cpu leg also rejects an unknown compile option instead of falling back. The ROCm module skips with a named reason when `/dev/kfd`, the IREE HIP driver or a HIP device is missing; on this MI300X it really runs and the measured `max |rocm - numpy|` is 2 float32 ulp, inside the same rtol 1e-5/atol 1e-6 bound. `./backends/conftest.py` makes a missing extra loud when either leg is explicitly requested (`-m requires_iree` or `-m requires_rocm` exits 1) and only a warning when the directory is merely named, and `./backends/test_conftest.py` pins the implication table behind that decision (41 guard cases, no extra needed).
- `release_gate_no_jax.py` — in a clean subprocess, `import tensorneat` leaves `jax`, `jaxlib`, `optax`, `flax`, `torch`, `brax`, `gymnax` and `mujoco` out of `sys.modules` and survives a `sys.meta_path` finder that refuses each of them, the documented public surface resolves from this checkout, and a full XOR generation still runs.
- `test_release_gate_surface.py` — the package *surface* behind that root import: a subprocess walks and imports every module under `src/tensorneat` (87 of them, floor 80) and fails on any `NotImplementedError` (an unfinished port must not be laundered into a `support.lazy` skip) or on any `__all__` name that does not `getattr`; an in-process `ast` pass over every `.py` file (88, floor 80) rejects the forbidden eight in `import`/`from` forms and in `__import__("…")`/`….import_module("…")` literals, with a synthetic positive control; and a probe proves the shared import hook — not an absent installation — refuses each forbidden name.

## Shared infrastructure (`./support`)
`support/runner.py` is the ONLY place that touches `evoxc.build`/`evoxc.run`/`evoxc.lower`/`evoxc.compile`/`evoxc.load`: `build_defn(fn, *args, backend="numpy")` maps a `@evoxc.defn` (or any plain callable closure) plus its arguments to an executable, `run_defn(fn, *args)` builds and runs in one call, `run_graph(graph, *arrays)` compiles and runs a `Graph` (what `genome.grad` returns), and `to_numpy(tree)` unwraps `evoxc.Tensor` leaves of nested tuples/lists/dicts/namedtuples (a plain `tuple` is rebuilt rather than called).
`support/payloads.py` builds `int32`/`float32` gene payloads by hand (`node_keys`, `node_attrs`, `conn_keys`, `conn_attrs` as plain numpy arrays, with `I_INF`/`NaN` padding) plus the canonical small genomes (dense chain, skipped node, isolated node, recurrent ring).
`support/oracle.py` holds the numpy reference implementations the assertions compare against: the schedule derivation (field-for-field against `Transformed`), a NaN-aware forward pass, the four func-fit losses, and the CartPole Euler rollout; the Pendulum and MountainCar rollouts live in their own `./unit/problem` modules because they transcribe different dynamics.
`support/functions_ref.py` keeps the 12 ACT / 6 AGG reference kernels.
`support/lazy.py::require(module, *, allow_pending=False)` is the deferred-import helper the fixtures use: it imports a module at call time and, by default, lets every error through — `NotImplementedError` included, because a pending implementation in the library under test is a defect, not a skip.
`allow_pending=True` converts only a `NotImplementedError` whose innermost traceback frame lies inside `LIBRARY_DIR` (`src/tensorneat`, derived from the file) into a named `pytest.skip`, and names the module, file, line and function; a raise from anywhere else propagates, and no fixture in the suite opts in.
`support/test_lazy.py` pins that contract (9 tests), including the anti-hole case where `allow_pending=True` still propagates an out-of-library raise.

## Known items
`evoxc`'s power pullback computes `d(x²)/dx` as `y*b/a`, yielding `NaN` at `x == 0` where jax yields `0`; `./parity` differentiates at a differentiable point and records the corner rather than depending on it.
The bare whole-tree run reports two warnings, both `RuntimeWarning: overflow encountered in exp` from the `./unit/algorithm/test_hyperneat_e2e.py` runs; with the `bench` extra the `./parity` `mape` cases add `RuntimeWarning: divide by zero` from `evoxc`'s numpy divide.
The `nanobind: leaked …` lines the iree extension prints at interpreter shutdown are not pytest warnings.
`./backends/conftest.py` asks whether a test that carries only `requires_iree` is selected *because of* that marker: it evaluates the `-m` expression with the marker present and again with it absent, so `requires_iree` and `requires_iree or parity` request the leg while `not requires_iree`, `requires_iree and slow`, `parity` and the documented default gate `not parity and not slow` do not — a checkout without the extra no longer needs `--ignore=test/backends`, and `./backends/test_conftest.py` pins that table (plus the git-pinned install step) without needing the extra.

## Known divergences parity must tolerate
RNG draws differ by construction (`evoxc.random` splitmix64 vs `jax.random`), so parity never compares populations, mutations or crossovers — only kernels on identical payloads.
`genome.hash()` hashes differently (float32 row hash vs the legacy encoding) and is never compared.
Activation index `-1` means identity now, while the legacy `lax.switch(-1, …)` clamped to the last option: parity genomes avoid `-1` or exclude those nodes from the comparison.
All configured ACT/AGG options are evaluated and selected, so a non-total option can poison a gradient it is not selected into; parity gradient tests use single-option configurations.
The legacy forward aggregated over a full `max_nodes`-wide column with no in-degree truncation, so a parity genome must be constructed with `max_in_degree >= max_nodes` (or at least ≥ every node's real in-degree) to be comparable; otherwise dropped edges show up as `edge_overflow`.
`CustomFuncFit` samples from a seeded `Generator` instead of the global `np.random` state, so parity supplies fixed datasets (`method="grid"` or explicit arrays).
The legacy RL problems are gone, so CartPole, Pendulum and MountainCar have no parity oracle: `./unit/problem` is their only oracle, `support.oracle.cartpole_rollout` for CartPole and an in-file rollout per module for the other two.
`problem.finalize_fitness` maps NaN → `-inf` while the legacy pipeline left NaN in the fitness array, so parity compares finite fitness only and the mapping is pinned as the one deliberate divergence.
`mape` with a zero target is `1` for a zero prediction but `NaN` (`0/0`) when prediction and target are both exactly zero on the legacy side; parity genomes are chosen to avoid that corner.
A NaN *source slot* is dropped when the destination also has a live source, so an isolated node poisons only a read-out that has no other live input; both halves of that rule are pinned in `./parity` and `./unit/genome`.

## Conventions
No test body is a placeholder: every test either asserts on a real kernel or is skipped because an optional dependency is absent (`./parity` without `jax`).
`jax` is imported only inside `./parity` modules, and only after `pytest.importorskip("jax")`; no other test may import it at module scope, and `test/unit/conftest.py` enforces that with a session-baseline `sys.modules` diff plus an import recorder that attributes the offending file.
The two release gates name the forbidden frameworks only inside subprocess script strings — `release_gate_no_jax.py` under the refusing import hook, `test_release_gate_surface.py`'s probe on purpose — so no such import ever runs in the pytest process.
A behaviour the implementation documents but does not deliver is pinned with `xfail(strict=True)` and a reason starting `src defect:` — never removed, never softened.
Shapes and keys in the suite are small (pop ≤ 16, `max_nodes` ≤ 16) except where a test exists specifically to exceed a static bound.
No network, no GPU, `backend="numpy"` everywhere except tests marked `requires_iree`.
Files stay under ~1000 lines; one test module per source module, named `test_<module>.py`.

## Constraints
`release_gate_no_jax.py` does not match pytest's default `python_files` patterns, so `conftest.py::pytest_collect_file` explicitly collects that one filename; do not rename it without editing the hook.
`test_release_gate_surface.py` matches the default `test_*.py` pattern, so it needs no hook; it imports `release_gate_no_jax` for `FORBIDDEN`, the subprocess environment and the import hook, which works because `conftest.py` puts `test/` on `sys.path`.
`FORBIDDEN` lives only in `release_gate_no_jax.py`; adding a framework there strengthens every gate at once, and the surface gate's `MIN_MODULES`/`MIN_FILES` floors are what stop an empty walk or scan from passing.
A test may not edit `../src`, `../benchmarks` or `pyproject.toml`: cross-node needs go into the report to the parent.
Suite output must be deterministic — a flaky test is a bug in the test, not a `pytest.retries` candidate (the plugin is not installed).
