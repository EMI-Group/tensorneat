# ./test/unit/common — numpy-backend suites for `tensorneat.common`

## Intent
Prove that the bottom layer of the package computes what its docstrings promise: the execution schedule (`tensorization`), the flat-index kernel helpers (`tools`), the ACT/AGG registries and dispatchers (`functions`), the host code generation (`sympy_tools`), the immutable host container (`state`) and the host graph algorithms (`host_graph`).
Every test body holds real assertions; there is no `pytest.skip` and no `xfail` in this directory.
Every assertion compares against something *independent* of the implementation it checks: a plain-numpy oracle written in the test module, `support.oracle.schedule`, `host_graph.node_depth` as the counterpart of the in-graph `node_level`, a closed form, the evoxc forward as the authority for code generation, or a hand-enumerated literal for a genome small enough to write out.
The suite runs in the default gate (`pytest -m "not parity and not slow"`) on `backend="numpy"`.

## How to run
`uv run pytest -o addopts="" -q test/unit/common` from the repo root after `uv sync --all-extras` — 246 passed, ~5 s.
246 = `test_tools.py` 49 + `test_sympy_tools.py` 42 + `test_functions.py` 36 + `test_tensorization_seams.py` 31 + `test_tensorization.py` 22 + `test_host_graph.py` 21 + `test_state.py` 20 + `test_tools_prepared.py` 15 + `test_tensorization_validate.py` 10.

## What each module proves
`./test_tensorization.py` (22) — `derive_schedule` on hand-built payloads: the twelve `Transformed` fields with their documented shapes and integer dtypes (`level`/`overflow` are read-only aliases of `node_level`/`edge_overflow`, not extra fields), input nodes pinned at level `0`, the longest-path recursion over the payload's own decoded edges, `I_INF` for absent/isolated/cyclic nodes, incoming-edge windows dense in connection-row order with `I_INF` padding and `in_src`/`in_conn`/`in_valid` agreeing cell for cell, `edge_overflow` counting exactly the dropped edges, field-by-field equality with `support.oracle.schedule`, `topo_key` as a valid execution order, `key_slot_table`/`slot_lookup`, the missing-output-key miss slot, and the `float32`+`NaN` spelling producing the identical schedule as `int32`+`I_INF`.
`./test_tensorization_validate.py` (10) — `validate_schedule` accepts the kernel output and rejects each tampered invariant (field shape, dtype, `I_INF` level with a finite `topo_key` and vice versa, wrong `topo_key` formula, negative `edge_overflow`, out-of-range input slot, live level with dead `in_valid`, `in_conn`/`in_src` disagreement), matched on the specific `ConfigError` message.
`./test_tensorization_seams.py` (31) — the third module of the `tensorization` family: `acyclic=True` derives the byte-identical schedule to `acyclic=False` and to `support.oracle.schedule` on a cycle-free population (chain, bypass and `P = 2` chain), while on a `ring_payload` it *saturates* the cycles the detecting path reports as `I_INF` (finite, non-row-monotone levels that `validate_schedule` still accepts — the documented silent-wrongness that only a feedforward genome may buy); plus every refusal of `derive_schedule` and `node_levels`, each matched on its own `ConfigError` message and paired with a control call that differs in exactly one argument (non-positive statics, the three `_check_shape` disagreements, a key vector longer than `max_nodes`, a key array in the other spelling, the missing edge triple, and the population/connection/node-axis mismatches).
`./test_tools.py` (49) — `I_INF`/`KEY_MAX` sentinels, `batch_offsets`, `flat_gather`/`masked_flat_gather`, `flat_scatter`/`masked_flat_scatter`, `fetch_first`, `fetch_random`, `rank_elements`, `argmin_with_mask`, `mutate_float`, `mutate_int` and `hash_rows` against a numpy expression, a Python loop or a stated law, including the out-of-range behaviour (evoxc raises a `ShapeError` where JAX clamped, so the masked helpers sanitize *and* mask), the dump-slot rule for dropped writes, the neutral-element fills, and key-only determinism of both mutators.
`./test_tools_prepared.py` (15) — the second module of the `tools` family: `prepare_flat_index` with `trusted=True` agrees with `trusted=False` and with the `row * R + col` oracle on every in-range index, and the two diverge exactly at an escaping cell (the raw column — which lands inside the neighbouring row for `R <= col < 2R`, and wraps for a negative one — versus the redirect to `P * R`); `flat_gather_prepared`/`flat_scatter_prepared` on a trusted block match the one-shot wrappers, the masked `present`/`fallback` replacement happens before the index is formed, `masked_flat_scatter` keeps its dump-column redirect under `trusted=True`, and an untrusted escaping block (hand-built `P * R`) raises the same `evoxc.ShapeError` the one-shot wrappers are pinned on.
`./test_functions.py` (36) — literal `ACT`/`AGG` option tables (12 / 6) and sympy counterparts, `FunctionManager` name↔id↔kernel↔sympy pairing plus its `ValueError`/`IndexError`/`AttributeError` paths and the `get_func_name`-is-absent check, `random_index` staying in `[0, len)` over seeded keys, `apply_activation`/`apply_aggregation` against both a per-option runner loop and `support.functions_ref` for every id (incl. NaN, masked-out slots, all-`False`/all-`True` columns, `maxabs` sign/tie, `mean` real edge count, `-1`/out-of-range ⇒ identity, integral `float32` ids), each aggregation's neutral padding and `has_valid` zero guard, and the sympy counterparts against the kernels through `sp.lambdify` plus `to_python_code` source `exec`-ed against numpy.
`./test_sympy_tools.py` (42) — `to_python_code` emits runnable NumPy source for **every** shipped option, checked option by option: for each of the 12 ACT ids and 6 AGG ids the emitted snippet is `exec`-ed in a namespace holding `np` and `i` and its `o[0]` matches the evoxc `genome.forward` on the same payload within `1e-5` (worst measured 2.5e-7) and, where a reference kernel applies, `support.functions_ref` on the hand-computed pre-activation; `to_latex_code` returns a balanced `align` block with one `&=` line per useful non-input node for every option (`maxabs` is the only one rendering a `\begin{cases}` Piecewise); `input_symbols` drives the binding header and the empty-list fallback recovers it from the referenced `i<k>` symbols; `output_exprs` sets the output count and the comment block, with the `o<k>`-key fallback when it is empty; a `sympy_output_transform` doubles the emitted result; a `useful_nodes` set that omits a node drops its line from both renderers; and a sympy function NumPy lacks raises `ConfigError` naming the culprit instead of emitting an undefined name.
`./test_state.py` (20) — `State` access/`KeyError`/`__contains__`/insertion order/legacy `repr`, `register`/`update`/`remove` returning new containers and leaving the original untouched (wrong direction ⇒ `ConfigError`, assignment ⇒ `AttributeError`), `save`/`load` round-trip in `tmp_path` with the raw pickle payload read back by a recording `Unpickler`, error propagation for a missing/garbage/truncated file, `copy.copy` sharing and `copy.deepcopy` replacing the payload while keeping every entry, a `pickle` round-trip that restores a usable container (re-savable, readable by both spellings, still raising `StateKeyError` on a miss), `tree_flatten`/`tree_unflatten` pairing and length validation, and evoxc pytree registration through `evoxc.tree_flatten`/`tree_map`/`tree_unflatten`.
The one miss-contract test is `test_missing_entry_is_an_attribute_error_and_a_key_error`: a bare `state.typo` raises the concrete `common.state.StateKeyError`, which is an `AttributeError` and a `KeyError` at once, so `hasattr(state, "typo") is False` and `getattr(state, "typo", None) is None` while `state["typo"]` raises the plain builtin `KeyError` that is neither.
`./test_host_graph.py` (21) — `decode_graph` (`NaN` padding skipped, keys cast to `int`, `GraphError` on a duplicate node key / absent endpoint / bad fixed prefix), `topological_sort` (ascending layers, deterministic, argument not mutated, `GraphError` on a cycle or unknown endpoint), `find_useful_nodes` (backward closure, terminates on a cycle), `check_cycles` (self-loop, back-edge, existing-edge and forward-edit cases), `node_depth` (hand-enumerated longest path, `GraphError` on a cycle / unreachable / feedless node, with the unreachable case asserting the message names the *one* node the walk cannot pin).

## Fixtures
`./conftest.py` owns the three lazy inputs: `common` (a plain module-scoped accessor for `tensorneat.common`), and `payloads` / `oracle` (`support.payloads`, `support.oracle`, resolved with `pytest.importorskip` so a bare environment skips instead of erroring).
`seed`, `rng` and `evoxc_key` come from `../conftest.py`; a key-taking helper is wrapped by `test_tools._seeded` / `_run_seeded` because the runner cannot carry an `evoxc.Tensor` key as a graph input.
Module-local fixtures name the genome each test starts from so a test signature states its topology (`tiny`, `chain_payload`, `skip_payload`, `isolated_payload`, `ring_payload`, `sparse_payload`, `state`, `payload_state`, `feedforward`, `cyclic`, `gene_rows`).
`test_host_graph.py` adds an `errors` fixture that imports the public `tensorneat.common.errors` rather than the names `host_graph` happens to re-export.
`test_tensorization_seams.py` relative-imports the payload fixtures and `_float_keys`/`_key_span`/`_decode`/`DOCUMENTED_FIELDS` from `test_tensorization.py` and adds only its own `_call` (the raw positional `derive_schedule` call site, needed for a wrong static or the `acyclic` flag) and `_levels` (a traced `node_levels` call site); `test_tools_prepared.py` imports `_np_flat_gather`/`_np_flat_scatter` from `test_tools.py` the same way.
`test_sympy_tools.py` builds its genome with `DefaultNode(activation_options=ACT.evoxc_fns, aggregation_options=AGG.evoxc_fns)` and runs one traced closure that calls `genome.transform(state, node_keys, conn_keys)` then `genome.forward(state, transformed, ...)`, so the graph forward is the oracle for the generated source.

## Gotchas of this module family
`derive_schedule`'s five statics are positional-or-keyword and `evoxc.trace.defn.Defn` is directly callable (it also exposes `.fn`), so `run_defn(derive_schedule, …, int(max_in_degree), int(key_span))` is the whole call — no `functools.partial` dance; `acyclic` is a sixth, plain-bool static baked into the trace.
`derive_schedule` accepts **both** key spellings (`int32`+`I_INF` canonical, `float32`+`NaN` the legacy/parity spelling); the tests assert the two spellings yield identical schedules instead of treating the mismatch as a doc conflict, and mixing them in one call is a `ConfigError`.
`support.oracle.schedule` returns the full post-merge `Transformed` field set, so the comparison is field-by-field with no substitution.
`edge_overflow` is *data*, never an exception, and `level == I_INF` is the schedule's way of reporting a cycle where `host_graph.node_depth` raises `GraphError` — a recurrent genome has no depth agreement by design and none is asserted.
A missing output key is *reported* as `output_slot == I_INF` by the kernel; only the host-side helpers raise.
The dispatchers take `act_fns`/`agg_fns` as trace-time static arguments, so a custom option tuple must be bound (e.g. `functools.partial(apply_activation, act_fns=...)`), never passed as a traced argument.
`FunctionManager.random_index` draws `evoxc.random.randint(key, (1,), 0, len)` and reshapes to rank 0, because a 0-d numpy-backend draw is rejected while the output tensor is built.
`sympy_module()` emits only the counterpart classes that define `numerical_eval` (`SympyClip` for ACT, an empty mapping for AGG) — not every registered option.
`to_python_code` emits bare `exp(...)`, so the generated snippet needs numpy's names in its namespace to run.
`DefaultNode()` ships one activation option (`ACT.sigmoid`) and one aggregation option (`AGG.sum`), so a codegen test that varies the option id must pass the full `ACT.evoxc_fns` / `AGG.evoxc_fns` tuples to the gene; a bare name string is rejected (`_option_list` takes callables).
`genome.network_dict(state, payload.args(), whether_re_cound_idx=False)` takes the four payload arrays as **one** tuple argument, and `whether_re_cound_idx=False` keeps the payload's own keys (the default renumbers hidden keys above the input/output keys).
`to_python_code`'s `output_exprs` drives only the output count (`o = np.zeros(len(output_exprs))`) and the trailing comment block — the per-node assignment lines come from `nodes_exprs` — and `input_symbols` drives only the binding header, which is documentation: reordering it rewrites the header and leaves the body's `i[k]` mapping fixed by the `i<k>` symbol names.
`State` defines no `__eq__`, so "the round-tripped state equals the original" is checked structurally (`test_state._content` + `np.array_equal` for the tensor payload), never with `==`.
`evoxc` rejects a static `NaN` at run time ("graph was specialized on nan"), so `masked_flat_gather`'s default `fill` is reached through a closure that bakes it into the trace.
`node_levels` validates the connection axis by looping over `src`/`dst`/`edge_valid` against `src`'s width, so a *short* `src` can never be rejected — only a longer one; no test asserts that unreachable branch.
`test_tensorization_validate.py` is the `validate_schedule` half of a two-module pair covering one source module; pytest resolves a fixture's own dependencies in the *using* module's namespace, so the payload fixtures travel with its relative import.
A parametrized case may legitimately carry several variants (mutation rates, neutral elements, tampered invariants, option ids) — the counts are the design, not an accident.

## Known gaps
`derive_schedule`'s in-graph behaviour for a key outside `[0, key_span)` (a dropped edge, reported as `I_INF`) is covered only indirectly, through the overflow and missing-output-key tests.
`apply_aggregation` has no custom-`agg_fns` test (the ACT side has one), so the `window_body` / `zero_on_empty` protocol, the guard emitted for an unannotated kernel, and the empty-list `enp.zeros` return are unpinned.
`common/sympy_tools.py::analysis_nodes_exprs`, `round_expr` and `replace_variable_names` are covered only through `to_python_code`/`to_latex_code`; there is no direct test of the `norm*` substitution or of the `ConfigError` for an unknown `mode`.
`tools.to_numpy` and `tools.hash_rows`'s row-padding/empty-column branches are untested here; `StatefulBaseClass.show_config` is untested anywhere (Pipeline overrides it).
Timing-sensitive bands: `test_fetch_random_is_uniform_over_the_row` (4.5σ) and the `mutate_float` law test (3σ on a 4000-element draw) ride a crc32-of-node-id seed, so a rename re-rolls them.

## Constraints
Backend is always `"numpy"`; no `requires_iree` case lives here (every kernel under test is numpy-backend only, so an iree variant would prove nothing new).
No test module imports `jax`/`torch` at module scope or in a body; `sympy` is imported inside the tests that need it.
`import tensorneat.common` executes `src/tensorneat/__init__.py`, which imports no optional framework, so the guard's baseline stays empty and the per-test diff watches only what a test itself pulls in.
`import tensorneat` is usable, so nothing here is gated behind a "not implemented" skip.
Files stay ≤ ~1000 lines with one source module per file; the `tensorization` (three modules) and `tools` (two modules) families are the documented exceptions, `test_functions.py` sits exactly at the 1000-line threshold, and a further addition to it must start a `test_functions_*.py` sibling.
Nothing here is exported or packaged.
A test may not edit `../../../src`, `../../../benchmarks` or `pyproject.toml` — a discovered defect is reported to the parent instead of patched here.

## Routing Table
No subdirectories — this node is a leaf.
